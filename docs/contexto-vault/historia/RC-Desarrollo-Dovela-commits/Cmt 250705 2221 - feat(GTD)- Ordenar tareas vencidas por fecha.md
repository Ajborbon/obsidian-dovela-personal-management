Añade la funcionalidad para ordenar la lista de tareas vencidas (Overdue) de forma cronológica.

Este cambio modifica el generador de HTML para que, antes de renderizar la vista, ordene las tareas vencidas por su fecha, asegurando que las más antiguas aparezcan primero. Esto facilita la visualización y priorización de las tareas que requieren atención urgente.
